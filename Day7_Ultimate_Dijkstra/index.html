Theory & How it Works 🧠

                        

                            

                                
1. Initialization

                                
Set distance to Start Node = 0 and all others to Infinity (∞). This marks all other nodes as "unreachable" until we explore them.

                            

                            

                                
2. The Greedy Choice

                                
Always pick the unvisited node with the smallest distance. This ensures that when we process a node, we've found the shortest path to it.

                            

                            

                                
3. Edge Relaxation

                                
This is the most important part! For every neighbor v of current node u:
