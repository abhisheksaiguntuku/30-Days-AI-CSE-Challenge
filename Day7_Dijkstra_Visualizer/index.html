Dijkstra's Algorithm: The GPS Logic 🧠

Dijkstra's algorithm is the foundation for almost every navigation system in the world. It finds the shortest path between a starting node and every other node in a graph.

How it works (Step-by-Step):

  1. Initialize: Set the distance to the Start node to 0, and all other nodes to Infinity.
  2. Explore: Look at the neighbors of the current node. Calculate their distance from the start.
  3. Update: If the new path is shorter than what we knew before, update the distance.
  4. Repeat: Always pick the node with the smallest distance next. This is why it's called a "Greedy" algorithm.

Why is it special?

Unlike simple search algorithms, Dijkstra's is Guaranteed to find the shortest possible path. It doesn't just find a way; it finds the best way.
